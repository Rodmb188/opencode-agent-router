## 📌 O que é recursão?

**Recursão** é quando uma função **chama a si mesma** para resolver um problema. É como se a função resolvesse uma parte do problema e depois pedisse ajuda a si mesma para resolver o restante.

---

## 📌 Exemplo simples: Calculando o fatorial de um número

Vamos calcular o **fatorial** de um número. O fatorial de um número `n` é dado por:

```
n! = n × (n-1) × (n-2) × ... × 1
```

Por exemplo:
- 5! = 5 × 4 × 3 × 2 × 1 = 120
- 3! = 3 × 2 × 1 = 6

Vamos criar uma função recursiva para calcular o fatorial.

---

## 📌 Função recursiva para calcular o fatorial

```python
def fatorial(n):
    if n == 1:
        return 1
    else:
        return n * fatorial(n - 1)
```

---

## 📌 Passo a passo: Calculando `fatorial(5)`

Vamos ver como a função funciona passo a passo.

1. `fatorial(5)` → chama `fatorial(4)`
2. `fatorial(4)` → chama `fatorial(3)`
3. `fatorial(3)` → chama `fatorial(2)`
4. `fatorial(2)` → chama `fatorial(1)`
5. `fatorial(1)` → **retorna 1**

Agora começa a "subir" os valores:

6. `fatorial(2)` → `2 * 1 = 2`
7. `fatorial(3)` → `3 * 2 = 6`
8. `fatorial(4)` → `4 * 6 = 24`
9. `fatorial(5)` → `5 * 24 = 120`

👉 **Resultado final: 120**

---

## 📌 Conclusão

- A recursão é útil quando podemos dividir um problema em partes menores e semelhantes.
- Cada chamada da função resolve uma parte do problema.
- A **condição de parada** (no caso, `n == 1`) é essencial para evitar uma chamada infinita.

### O Segredo da Recursão
Para que a recursão funcione e não cause um erro infinito, ela precisa de duas partes obrigatórias:
1.  **Caso Base:** A condição que para a recursão (o "fim da linha").
2.  **Passo Recursivo:** A parte onde a função chama a si mesma, geralmente com um problema menor.

---

### Exemplo Prático: Fatorial

Vamos calcular o **fatorial** de um número.
*   O fatorial de 5 (`5!`) é `5 × 4 × 3 × 2 × 1 = 120`.
*   A fórmula recursiva é: `n! = n × (n-1)!`

#### Código em Python (Simples)

```python
def fatorial(n):
    # 1. CASO BASE: Se n for 1, paramos e retornamos 1.
    if n == 1:
        return 1
    
    # 2. PASSO RECURSIVO: A função chama a si mesma com (n - 1)
    return n * fatorial(n - 1)

# Chamada inicial
resultado = fatorial(5)
print(resultado) # Saída: 120
```

---

*   `n` é 5. Não é 1, então vai para o passo recursivo.
*   Operação: `5 * fatorial(4)`
*   *Aguardando resposta de `fatorial(4)`...*

def fatorial(n):

O **custo de oportunidade** é, basicamente, o conceito de que toda escolha que fazemos implica deixar de fazer outra coisa. Em economia, nada é realmente "grátis", porque para obter algo, você precisa abrir mão de algo que poderia ter feito ou comprado com os mesmos recursos.

Vamos explicar isso de forma bem didática, passo a passo:

---

### 1. A Ideia Central: "Escolher é Renunciar"
Imagine que você tem **R$ 50,00** e dois desejos:
- Um livro novo.
- Um ingresso de cinema.

Você não tem dinheiro para os dois. Se você escolher o **livro**, o custo de oportunidade não é apenas os R$ 50,00. É o **ingresso de cinema** que você deixou de ter.

> **Definição simples:** Custo de oportunidade é o valor da **melhor alternativa** que você não escolheu.

---

### 2. Um Exemplo do Dia a Dia
Pense na sua hora de almoço:

- **Opção A:** Comer no restaurante da empresa (custa R$ 20,00).
- **Opção B:** Levar comida de casa (custa R$ 5,00).

Se você escolher comer no restaurante, o custo de oportunidade não é só o dinheiro gasto. É também:
- Os R$ 15,00 a mais que você pagou.
- O tempo que você perdeu cozinhando em casa na noite anterior (se tivesse levado de casa).
- A conveniência de ter algo pronto imediatamente.

O custo de oportunidade ajuda a medir o "preço real" da sua decisão, considerando não só o dinheiro, mas também tempo, esforço e satisfação.

---

### 3. Por Que Isso é Importante?
O custo de oportunidade nos lembra que **recursos são escassos** (dinheiro, tempo, energia). Como não podemos ter tudo ao mesmo tempo, precisamos decidir qual opção traz mais **benefício** para nós.

#### Exemplo Clássico: Estudar vs. Trabalhar
Um estudante pode:
1. Trabalhar meio período e ganhar R$ 1.000,00 por mês.
2. Estudar em tempo integral para melhorar sua nota média.

Se ele escolher estudar, o custo de oportunidade são os **R$ 1.000,00 que ele deixou de ganhar** + o lazer que deixou de ter. Isso não significa que estudar é "ruim", mas sim que a decisão tem um preço oculto.

---

**Principais correções feitas:**

*   **relatorios** → **relatórios**: Precisa de acento circunflexo por ser oxítona com ditongo aberto.
